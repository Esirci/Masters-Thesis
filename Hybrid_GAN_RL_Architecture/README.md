# Project Structure and File Descriptions

This document provides a detailed overview of the files in this project folder (`Hybrid_GAN_RL_Architecture`). The project implements a **Hybrid GAN-RL Architecture** for Hardware Trojan Detection, achieving 100% accuracy on the benchmark dataset.

---

## Documentation
- **`Experiment_Report.md`**: The comprehensive final report documenting the full research process — baseline reproduction, GAN augmentation, RL training, SHAP analysis, data quality audit, and the final 100% result (9 sections, March 2026).
- **`GAN_Data_Quality_Issues.md`**: Detailed report on data quality issues discovered in the initial CTGAN-generated synthetic data (negative values, int64 overflow), root cause analysis, and the resolution applied (Solution A — per-column clamping).

---

## Datasets
- **`short_csv.csv`**: Original source dataset. 509 benchmark circuits × ~605 extracted structural/functional features. Class imbalance: 418 Trojan (82%) vs 91 Non-Trojan (18%).
- **`train_split.csv`**: Training split (407 samples). Generated by `create_splits.py`.
- **`test_split.csv`**: Holdout test split (102 samples). Never touched during training.
- **`train_split_augmented.csv`**: Balanced training dataset: 334 Trojan + 334 Non-Trojan (261 synthetic). Generated by `gan_augmentation.py`.

---

## Scripts

### Data Preparation
- **`create_splits.py`**: Generates stratified 80/20 train/test splits from `short_csv.csv`. Key feature: **forced assignment** — `c6288.txt` (the only clean c6288 circuit) is explicitly pinned to the training set before splitting to prevent the data representation gap that caused a persistent False Positive.

### Baseline
- **`baseline_dnn.py`**: Reproduces the reference DNN (5 × Dense-20-ReLU layers). Establishes baseline: **97.06% Accuracy, 5.56% FPR, 2 missed Trojans**.

### Hybrid GAN + RL Architecture
- **`gan_augmentation.py`**: Trains CTGAN on the 73 Non-Trojan training samples and generates 261 synthetic clean samples. Includes **per-column physical constraint enforcement** (clipping to `[real_min, real_max]` + safety sweep) to prevent physically-impossible values (e.g., negative gate counts).
- **`trojan_env.py`**: Custom OpenAI Gym environment (`TrojanEnv`) wrapping the dataset. Defines the asymmetric reward function: `+1` correct, `-1` False Negative, **`-20.0` False Positive** (heavily penalizes clean-chip misclassification).
- **`train_rl.py`**: Trains a **DQN (Deep Q-Network)** agent on `train_split_augmented.csv`, evaluates on `test_split.csv`. Final result: **100% Accuracy, 0 FP, 0 FN**.
- **`dqn_trojan_detector.zip`**: Saved trained DQN model (Stable-Baselines3 format).

### Analysis & Diagnostics
- **`analyze_errors.py`**: Identifies the filenames of misclassified samples in prediction output. Used to pinpoint `c6288.txt` as the persistent False Positive.
- **`shap_analysis.py`**: SHAP (SHapley Additive exPlanations) analysis using `KernelExplainer` on the DQN Q-value difference. Explains feature-level contributions to the `c6288.txt` misclassification (top features: `Median High fan_in_2`, `No of NOR`).
- **`inspect_augmented.py`**: Data quality validation script for `train_split_augmented.csv`. Classifies remaining negatives as valid (present in real data) or invalid (should have been clipped), and reports totals per category.

### 5-Fold Cross-Validation Pipeline *(Phase 2 — post-supervisor review)*
- **`create_cv_splits.py`**: Generates 5 stratified folds from `short_csv.csv` → `cv_splits/` folder (10 files).
- **`gan_augmentation_cv.py`**: Per-fold CTGAN augmentation with physical constraints → `cv_augmented/` folder. Called with `--fold N`.
- **`train_rl_cv.py`**: Per-fold DQN training and evaluation → `cv_results/` folder. Called with `--fold N`.
- **`run_full_cv.py`**: Orchestrator — runs GAN + RL for all 5 folds, then prints and saves the full mean ± std summary.

---

## CV Output Folders
- **`cv_splits/`**: 5 × (train.csv + test.csv) fold pairs — pure stratified split, no forced assignments.
- **`cv_augmented/`**: 5 × GAN-augmented training sets (independently trained per fold).
- **`cv_models/`**: 5 × saved DQN models (`fold_N_dqn.zip`).
- **`cv_results/`**: 5 × per-fold JSON metrics + `cv_summary.json` (mean ± std).

---

## How to Reproduce

**Phase 1 — Single split (historical):**
```bash
python create_splits.py          # Generate train/test splits
python gan_augmentation.py       # Generate constrained synthetic data (~7 min)
python train_rl.py               # Train DQN agent and evaluate (~15 sec)
```

**Phase 2 — 5-Fold Cross-Validation (current/recommended):**
```bash
python create_cv_splits.py       # Generate 5 stratified folds
python run_full_cv.py            # Run full pipeline for all 5 folds (~40 min)
```

**Optional diagnostics:**
```bash
python baseline_dnn.py           # Confirm baseline metrics
python inspect_augmented.py      # Verify 0 invalid negatives in augmented dataset
python shap_analysis.py          # SHAP explainability (requires shap library)
```
